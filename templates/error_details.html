How This Page Works
This page analyzes only participants with custom enrollment periods. For each participant, it fetches the number of days with data for each sensor within their custom enrollment range. Each sensor gets its own section below, showing participants where that sensor has fewer days of data than the maximum across the other sensors. The threshold controls the minimum gap size to report.
