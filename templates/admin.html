📊 LemurDX Data Dashboard

Welcome to the admin dashboard - Monitor and export sensor data

🔍

Data Validation

Primary Tool: Monitor data quality and completeness for all users.

• View all users in a table with sensors as columns
• See date ranges and data status at a glance
• Filter by sensor type
• Download individual sensor data or full reports
📥

Export Data

Focused Export: Download specific sensor data for individual users.

• Select user, device, and sensor type
• Choose custom date ranges
• Export to CSV format
• View available data ranges
⚠️

Sensor Coverage Errors

Gap Analysis: Find participants where a specific sensor has fewer data days than others.

• Only shows participants with custom enrollment periods
• Select a reference sensor to check
• Configurable day-difference threshold
• Per-sensor day counts within enrollment range
👥

Participant Data Download

Batch Export: Download data for multiple participants by sensor type.

• Select multiple participants at once
• Download by sensor type
• Each participant gets separate CSV
• Includes dates in each row
• Filter by custom dates
